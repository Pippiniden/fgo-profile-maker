# FGO風キャラ紹介メーカー

自作イラストや文章を使って、**Fate/Grand Order（FGO）風のキャラクター紹介・プロフィール画面画像**をブラウザ上で作成する、非公式のファンメイドツールです。

## できること

### キャラ紹介画像

`index.html` から使用できます。

- 1024×1024 のキャラ紹介画像を作成
- キャラクター画像の読み込み
- 魔法陣の表示・色・透明度などの調整
- クラス名・プロフィール・キャッチコピー・キャラクター名の編集
- レアリティ表示（C / UC / R / SR / SSR）
- 文字のフォント、サイズ、色、グラデーション、縁取り、影などを調整
- 各要素をドラッグして移動
- ホイールで拡大・縮小、Shift / Alt＋ホイールで回転
- スマートフォンではピンチ・回転操作に対応
- レイアウトや装飾を初期状態に戻す機能

### ステータス画面

`status.html` から使用できます。

- 1280×720 のプロフィール／ステータス画面風画像を作成
- キャラクター画像、クラス、名前、プロフィール、パラメータなどを編集
- カード部分の画像位置・拡大率を調整
- CSSで構成したフレームを使用
- 自作フレーム画像の読み込みにも対応

## 保存形式

画像の保存時に、以下から選択できます。

- **PNG** — 高品質・可逆圧縮
- **WebP（品質80%）** — ファイルサイズを抑えたい場合向け

WebPはブラウザ内で品質80%として再エンコードします。元のPNG出力もそのまま利用できます。

## 使い方

### Web上で使う

GitHub PagesなどのWebサーバー上に配置して、`index.html` または `status.html` を開いてください。

### ローカルで使う

ファイルを直接開く方法では、ブラウザのセキュリティ制限によってフォントや画像の書き出しが正常に動作しない場合があります。

そのため、ローカルで使用する場合も簡単なHTTPサーバー経由で開くことを推奨します。

## プライバシー

キャラクター画像など、ユーザーが読み込んだ画像は**画像生成のためにブラウザ内で処理され、サーバーへアップロードされません**。

ステータス画面の画像書き出しでは、`html-to-image` を使用しています。
